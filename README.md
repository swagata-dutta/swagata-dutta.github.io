## 🔬 Research Interests

- **Spectral Graph Theory:** Investigating eigenvalues, eigenvectors, and spectra of graph matrices (adjacency, Laplacian, signless Laplacian) to deduce structural properties and connectivity.
- **Permanental Polynomials:** Analyzing algebraic properties, root distributions, and coefficient behaviors to characterize graph classes.
- **Combinatorial Matrix Theory:** Algebraic graph theory, graph invariants, and matrix techniques in discrete mathematics.

## ✨ Features

- **Single-File Architecture:** Clean, self-contained `index.html` configured for GitHub Pages hosting.
- **Interactive Graph Theory Canvas:** Lightweight, dependency-free HTML5 Canvas background rendering a living mathematical graph with dynamic vertex drift and interactive mouse connections.
- **Mathematical Vector Motifs:** Subtle background SVG watermarks of iconic discrete structures (such as the *Petersen Graph*).
- **Responsive & Accessible:** Fully responsive design styled with Tailwind CSS, supporting mobile, tablet, and desktop views.
- **Theme Support:** Native Dark and Light mode toggle with persistent local storage and system preference detection.

## 🚀 Local Development & Preview

To preview the website locally on your computer:

1. Clone this repository:
   ```bash
   git clone https://github.com/swagata-dutta/swagata-dutta.github.io.git
   ```
2. Navigate into the project folder:
   ```bash
   cd swagata-dutta.github.io
   ```
3. Open `index.html` in any web browser:
   - On Windows: double-click `index.html` or run `start index.html` in PowerShell/CMD.
   - Or start a lightweight local server:
     ```bash
     python -m http.server 8000
     ```
     and visit `http://localhost:8000`.
